                                 💳📊 Credit Risk Segmentation Dashboard 💳📊

An interactive Power BI dashboard designed to segment loan records by risk category and surface the drivers behind loan defaults for data-driven lending decisions.

📌 Project Overview

This project analyzes loan default data using Power BI, DAX, and Excel to identify risk patterns across credit score, income, age, and employment categories.

The project analyzes **255,347 loan records**, segmented into risk-ready categories using custom DAX measures.

The analysis focuses on building KPI-driven risk segmentation, visualizing default patterns across multiple dimensions, and surfacing year-over-year trends to support lending decisions.

🎯 Project Objectives

- Segment loan records into risk categories by income, credit score, age, and employment type
- Engineer DAX measures to automate default-rate KPI calculations
- Build an interactive dashboard analyzing defaults across multiple dimensions
- Identify the overall default rate and its year-over-year trend
- Analyze average loan amounts by credit-score band

🛠️ Technologies Used

📊 Power BI
- Interactive dashboard development and data visualization

🧮 DAX
- Risk-category measures, calculated columns, KPI tracking

📗 Microsoft Excel
- Dataset inspection and preparation

📁 Dataset

- 📊 255,347 loan records
- 🔑 Key fields: Income Bracket, Credit Score, Age Group, Employment Type, Loan Amount, Default Status, Year

⚙️ Risk Segmentation

Engineered **17 DAX measures and calculated columns** to segment and analyze loan records, converting raw financial data into risk-ready categories:

- Income Brackets
- Credit Score Bins
- Age Groups
- YoY Default Change
- Default Rate by Employment Type

📊 Dashboard Design

Built a **3-page, 16-visual Power BI dashboard** using:

- Waterfall charts
- Treemaps
- Ribbon charts
- Stacked area charts

The dashboard breaks down loan defaults by credit score, income bracket, age group, and employment type.

📈 Key Findings

- Identified an overall **default rate of 11.6%** (29,653 of 255,347 loans)
- Surfaced year-over-year default trends across the loan portfolio
- Analyzed average loan amounts by credit-score band to support risk assessment

💡 Key Business Insights

- Default rate varies meaningfully across credit-score bands, income brackets, and employment types
- Year-over-year trend analysis surfaces whether risk is rising or falling across the portfolio
- Segmented, DAX-driven KPIs let a lending team drill into risk drivers interactively rather than reading a static report
